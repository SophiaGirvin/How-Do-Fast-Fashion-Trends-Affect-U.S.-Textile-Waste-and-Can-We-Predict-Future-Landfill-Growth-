# Fast-Fashion-Textile-Waste-Analysis
Statistical analysis and forecasting of U.S. textile waste trends to evaluate the environmental impact of fast fashion using Python, Pandas, and regression modeling.
# Fast Fashion Textile Waste Analysis

## Project Overview
This project investigates how fast fashion trends contribute to textile waste in the United States and uses statistical forecasting methods to predict future landfill growth.

## Research Question
How do fast fashion trends affect U.S. textile waste, and can future landfill growth be predicted?

## Tools
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Methods
- Data cleaning
- Exploratory data analysis
- Trend analysis
- Regression modeling
- Forecasting

## Results
Key findings showed increasing textile waste generation and projected continued growth under current consumption patterns.
